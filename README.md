# PAME. Greece

Mobile-first nationwide cafe, pub, bar and restaurant discovery using OpenStreetMap / Overpass. Next.js 15.

## Start

npm install
npm run dev

## Data integrity

No invented reviews, ratings, opening status or style classifications. Style tags are experimental and only match available metadata. Overpass public endpoints have rate limits and can fail. Production scale requires a cached geospatial database, attribution, provider-compliant review integrations, and background ingestion.
